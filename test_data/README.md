# Synthetic Test Fixtures

This directory contains synthetic court document test data used solely for local verification and automated testing of NayaSetu's extraction and legal analysis pipeline.

### Files
- **`sample_delhi_high_court_bail_order.pdf`**:
  - Synthetic 2-page digital legal order modeled after an Indian High Court bail proceeding.
  - Contains synthetic court name, case number, petitioner, respondent, dates, statutory provisions (Section 439 CrPC, Section 420 IPC, Section 120B IPC), and operative holding (*Bail Granted*).
  - Used for end-to-end integration testing and frontend verification.
  - Contains no private, classified, or real-person data.
